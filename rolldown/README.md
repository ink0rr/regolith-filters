# rolldown

Filter to run [Rolldown](https://rolldown.rs/) with Regolith.

## Settings

Refer to Rolldown [documentation page](https://rolldown.rs/reference/) for a complete list of settings.

### Default Settings

```json
{
  "input": "./data/scripts/main.ts",
  "external": [
    "@minecraft/server",
    "@minecraft/server-ui"
  ],
  "output": {
    "file": "./BP/scripts/main.js"
  }
}
```
